Why it matters

A file can be wrong
and still look completely normal.

Nothing about a tampered file necessarily looks different. The icon's the same, the file size might barely move, the timestamp can be spoofed. The only way to actually know a file hasn't changed is to compare it, byte for byte, against a version you trust.

🦠

Silent tampering

Ransomware and malicious scripts often modify files quietly, long before any visible symptom appears. By the time you notice, the damage is already done.

🖊️

Unauthorized edits

Financial records, contracts, configuration files: anything that shouldn't change without your knowledge deserves a witness that never blinks.

🔁

Honest mistakes

Not every change is malicious. Sometimes it's the wrong version saved over the right one. Integrity Monitor catches that too, and lets you undo it instantly.

How it works

Three steps. No configuration files, no servers to run.

01

Point it at a file

Choose any file on your device. Integrity Monitor computes its SHA-256 hash, a unique fingerprint where changing even one byte produces a completely different result.

02

It keeps watching

The app re-checks the file's hash continuously in the background, comparing it against the trusted fingerprint you started with.

03

You decide what happens

The moment a hash stops matching, you're alerted with exactly what changed and when. Reverse it back to the trusted version in one click, or accept it as the new baseline if the change was intentional.

Beyond monitoring

Back files up, and send them, without leaving the app.

Two more layers on top of monitoring: an encrypted off-site copy of the files that matter most, and a way to hand a file to someone else without emailing it around.

☁️ Encrypted cloud backup

Files are encrypted on your device before they ever leave it, then stored in your own Google Drive. Restoring verifies the hash before saving anything, so a corrupted or tampered backup is refused, not silently restored.

🌐 Long-range transfer

Send a file to anyone with an account, anywhere, using a short code instead of an email address. They approve it before it ever downloads.

📶 Short-range transfer

On the same WiFi? Send directly, device to device. No internet, no mobile data, protected by a one-time PIN so nobody else on the network can send you anything uninvited.

🔑 Password-gated retrieval

Downloading a backup or accepting a transfer asks for your password again first, so a device left unlocked can't be used to quietly pull your files.
